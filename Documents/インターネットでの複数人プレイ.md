## 何を持ってきたか

Mirai01 で作った「合言葉でつなぐ」仕組みのうち、**接続の設定画面とそれを動かす部分だけ**。
プレイヤー・アイテム・押せる箱などの**ゲームの中身は持ってきていない**。

| ファイル | 役割 |
| --- | --- |
| `Assets/Scripts/Network/InternetConnection.cs` | 部屋を作る／合言葉で入る／出る（Unity Relay） |
| `Assets/Scripts/Network/LanConnectionUi.cs` | 設定画面（遊び方を選ぶ → LAN／インターネット／1人） |
| `Assets/Scripts/Network/LanAutoStart.cs` | 起動引数での自動接続（`-nethost` / `-netjoin 合言葉` / `-host` / `-client IP`） |
| `Assets/Scripts/Network/LanConnectionLogger.cs` | 接続・切断・遅れをログに残す（`[NET]` `[LAN]` `[PING]`） |
| `Assets/Scripts/Network/NetworkStatusHud.cs` | 右上に遅れ（ping）を出す。**Mirai01 にあった得点の表示は外した** |
| `Assets/Scripts/Network/NetworkManagerCleanup.cs` | シーンを行き来したとき重なった `NetworkManager` を消す |
| `Assets/Scripts/UI/DraggableGuiPanel.cs` | ドラッグで動かせる・折りたためる枠 |
| `Assets/Scripts/Network/Editor/NetworkConnectSceneSetup.cs` | 接続シーンを作るメニュー（このリポジトリ用に新規） |
| `Assets/Scripts/Network/Editor/NetworkTestBuilder.cs` | 接続確認用のビルドと `.bat` を作るメニュー（このリポジトリ用に新規） |

追加したパッケージ（`Packages/manifest.json`）：

## 使えるようにするまでの手順

### 1. シーンを作る

Unityのメニュー **`Tools > Gamejam04 > オンライン接続シーンを作る`** を押す。
`Assets/Scenes/NetworkConnect.unity` ができ、ビルドの一覧にも足される。

### 2. Unity Cloud に登録する（インターネットでつなぐ場合だけ必要）

**このプロジェクトはまだ Unity Cloud につながっていない**（`ProjectSettings.asset` の `cloudProjectId` が空）。
登録しないと「部屋を作る」で「Unity Cloud への登録が済んでいません」と出る。LAN と 1人練習は登録なしで動く。

1. **`Edit > Project Settings > Services`** を開く
2. 組織を選ぶ → **Create a new cloud project** → **Link Unity project to cloud project**
3. ブラウザの Unity Cloud でプロジェクトの **Services** タブを開き、**Relay の「Launch」** を押す

> 有効化ボタンは無い。Relay の管理画面が開ければ使える状態。
> プロジェクトIDは `ProjectSettings.asset` に入り、Gitで全員に共有される（鍵やパスワードは入らない）。

### 3. 試す

中継サーバーを通るので、**1台のPCで .exe を2つ起動しても本当のやりとりが起きる**。
同じPCで2つ起動したときは自動で別人扱いになる（ログに `このPCで2番目の起動です`）。

1. Unityのメニュー **`Tools > Gamejam04 > 接続確認用のビルドを作る`** を押す
   （接続シーンが無ければ先に自動で作る。終わると `Build/NetworkTest/` が開く。Gitには入らない）
2. できたフォルダの `.bat` をダブルクリックする

| `.bat` | 何が起きるか |
| --- | --- |
| `LAN_2人で自動接続.bat` | ホストと参加者が1つずつ立ち上がり、そのままつながる。**まずこれで確認** |
| `LAN_4人で自動接続.bat` | ホスト1＋参加者3で4つ立ち上がる |
| `ネット_部屋を作る.bat` | インターネットで部屋を作る。**合言葉が画面に出るまで10〜20秒** |
| `ネット_合言葉で参加.bat` | 黒い画面に合言葉を打つと、その部屋に入る。**別のPCでも同じPCでもよい** |
| `2つ起動するだけ.bat` | 窓を2つ出すだけ。画面のボタンで操作したいとき |

**つながったかの見方**：ホストの左上の枠に「つながっている人数：2 人」、参加者の枠に「接続できています」、
右上の「通信の様子」に遅れ（ms）が出れば成功。

起動引数でも試せる：

```
ゲーム.exe -nethost          … 部屋を作る
ゲーム.exe -netjoin ABCDEF   … その合言葉の部屋に入る
```

## 設定できる値（`NetworkManager` オブジェクト）

| 部品 | 項目 | 初期値 |
| --- | --- | --- |
| Internet Connection | Max Players（ホスト込み） | 4 |
| Internet Connection | Session Name | Gamejam04 |
| Internet Connection | Is Private（合言葉を知る人だけ） | ON |
| Internet Connection | Region（空欄＝一番速い地域を自動） | 空欄 |
| Lan Connection Ui | Address / Port | 127.0.0.1 / 7777 |
| Lan Connection Logger | Ping Log Seconds | 10 |

## まだできていないこと

- **ゲームの中身が無い。** つながっても何も出てこない。プレイヤーを出すには
  `NetworkManager` の **Player Prefab** に、`NetworkObject` 付きのプレハブを入れる
- 画面は `OnGUI` の仮のもの。本番のタイトル画面は別に作る前提
- ホストが抜けると部屋ごと消える。再接続は無い
