## この機能は何か

**ゲームを起動して最初に出る画面。** いまは「指スマ」の文字と「スタート」ボタンだけ。
**スタートを押すと、指スマのシーン（`Yubisuma`）へ進む。**

- マウスでクリックして押せる
- **Enter／スペースでも押せる**（最初からスタートが選ばれた状態になっている。選ばれているとボタンが黄色くなる）
- ビルドの一覧の**先頭**に入れてあるので、ビルドした `.exe` はタイトルから始まる

---

## すぐ試す方法

1. `Assets/Scenes/Title.unity` を開いて再生する
2. 「スタート」を押す → 指スマの画面に切り替われば成功

作り直したいときは **`Tools > Gamejam04 > タイトル画面のシーンを作る`**（手で調整した内容は消える）。

## 関係するファイル

| 種類 | パス |
| --- | --- |
| スクリプト | `Assets/Scripts/Title/TitleMenu.cs`（スタートを押したらシーンを切り替える） |
| スクリプト（エディタ用） | `Assets/Scripts/Title/Editor/TitleSceneSetup.cs`（シーンを作るメニュー） |
| シーン | `Assets/Scenes/Title.unity` |

### シーンの中身

```
Title
├── Main Camera       ← 背景の色（紺）
├── EventSystem       ← ボタンを押すための係（Input System 用）
└── Canvas            ← TitleMenu
    ├── Title         ← 「指スマ」の文字
    └── StartButton   ← 「スタート」
```

## 設定できる値（`Canvas` の Title Menu）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| **Game Scene Name** | スタートで進むシーンの名前。**ビルドの一覧に入っている必要がある** | Yubisuma |
| Start Button | スタートのボタン | StartButton |

---

## できていないこと

- 見た目は仮のもの（文字は標準のフォント）。デザインはあとで差し替える
- 設定・終了などのボタンは無い
- 指スマの画面からタイトルへ戻る方法は無い
