## この機能は何か

**ゲームを起動して最初に出る画面。** 背景の絵（`Assets/Sprites/title.png`）と「スタート」ボタンだけ。

- **背景の絵**は画面いっぱいに敷く。絵（3:2）と画面（16:9）の形が違うので、**上端をそろえて下側だけを切る**（絵の上にあるタイトルの文字が切れないように）
- 絵にタイトルの文字が入っているので、前に置いていた「指スマ」の文字は**非表示**にしてある（消してはいない。`Canvas/Title` を表示すれば戻る）
- スタートボタンは、絵の真ん中（指先が触れ合うところ）を隠さないよう**画面の下のほう**に置いてある
- 背景の絵は **UI 用（Sprite）の読み込み設定**にしてある。初期設定のままだと横幅が 1536→2048 に引き伸ばされて絵が横に伸びるため（シーンを作るメニューが自動で切り替える）

**スタートを押すと、指スマのシーン（`Yubisuma`）へ進む。**

- マウスでクリックして押せる
- **Enter／スペースでも押せる**（最初からスタートが選ばれた状態になっている。選ばれているとボタンが黄色くなる）
- ビルドの一覧の**先頭**に入れてあるので、ビルドした `.exe` はタイトルから始まる

---

## すぐ試す方法

1. `Assets/Scenes/Title.unity` を開いて再生する
2. 「スタート」を押す → 指スマの画面に切り替われば成功

作り直したいときは **`Tools > Gamejam04 > タイトル画面のシーンを作る`**（手で調整した内容は消える）。

## 関係するファイル

| 種類 | パス |
| --- | --- |
| スクリプト | `Assets/Scripts/Title/TitleMenu.cs`（スタートを押したらシーンを切り替える） |
| スクリプト（エディタ用） | `Assets/Scripts/Title/Editor/TitleSceneSetup.cs`（シーンを作るメニュー） |
| シーン | `Assets/Scenes/Title.unity` |

### シーンの中身

```
Title
├── Main Camera       ← 背景の色（紺）
├── EventSystem       ← ボタンを押すための係（Input System 用）
└── Canvas            ← TitleMenu
    ├── Background    ← 背景の絵（RawImage ＋ AspectRatioFitter。画面を覆うように大きめに敷く）
    ├── Title         ← 「指スマ」の文字（背景があるときは非表示）
    └── StartButton   ← 「スタート」
```

## 設定できる値（`Canvas` の Title Menu）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| **Game Scene Name** | スタートで進むシーンの名前。**ビルドの一覧に入っている必要がある** | Yubisuma |
| Start Button | スタートのボタン | StartButton |

---

## できていないこと

- ボタンの見た目は仮のもの（白い四角と標準のフォント）。デザインはあとで差し替える
- 設定・終了などのボタンは無い
- 指スマの画面からタイトルへ戻る方法は無い
