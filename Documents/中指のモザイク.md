## この機能は何か

指スマで**中指が立ったとき、その中指にモザイクをかける**。

- 中指が**立って見えているときだけ**かかる（握りこぶしや「いっせーの」の間はかからない）
- セメントで上げたまま固定された指にもかかる（立って見えているため）
- 指が立っていく途中のアニメーションにもついていく
- 当てられて手が流れていくときは、手が消えるとモザイクも消える
- **M キーで、モザイクのあり／なしを切り替えられる**（いつでも押せる）。押すと画面に「モザイク：なし（M で切り替え）」と少しのあいだ出る。
  タイトルに戻って遊び直しても切り替えたまま。ゲームを閉じると「あり」に戻る。キーは `YubisumaMatch` の **Mosaic Toggle Key** で変えられる

## 仕組み

- モザイクそのものは TakumaS7 さんの `Assets/takuma/`（シェーダー `Mosaic-Overlay-ScreenSpace`、マテリアル `mosaic.mat`、プレハブ `mosaic.prefab`）。
  **四角い板の後ろに映っているものを、画面上で粗いマス目にして描く**シェーダー
- 各手に `YubisumaFingerMosaic` を付け、**中指の骨（MiddleFinger ～ Middle3 の先）に毎フレーム板を合わせる**。板はカメラのほうへ向ける
- 板は手の子ではなく、**プレイヤー（Player1／Player2）の下**に置いてある（`Mosaic_LeftHand` など）。
  右手のプレハブは左右反転（Scale X = -1）していて、手の子にすると板の大きさが狂うため
- このシェーダーは URP の **Opaque Texture** を使う。PC 向けの設定（`PC_RPAsset`）ではもともと ON。
  **Mobile 向けの設定（`Mobile_RPAsset`）は OFF なので、そちらで動かすとモザイクがかからない**

### ⚠ マテリアルのマス目の大きさについて

`mosaic.mat` の **Cell Pixel Size が 1** になっていて、そのままだと**モザイクがかからない**（1ピクセルのマス目＝元の絵と同じ）。
マテリアルは書き換えず、**`YubisumaFingerMosaic` の Cell Pixels At 1080 でマス目の大きさを決めている**。

## 付け方

**`Tools > Gamejam04 > 指スマの手に中指のモザイクを付ける`**

- **シーンを作り直さずに、今のシーンに付け足す**（手の位置などの調整は消えない）
- すでに付いている手には何もしないので、何度押してもよい
- 指スマのシーンを作り直すメニュー（`指スマの基礎シーンを作る`）でも、自動で付く

---

## 設定できる値（各手の `Yubisuma Finger Mosaic`）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Start Along | 板をどこから始めるか（付け根＝0、指先＝1）。付け根の骨は握りこぶしの中にあるので途中から | 0.15 |
| Beyond Tip | 指先からさらに先へはみ出させる割合 | 0.12 |
| **Width Scale** | 板の横幅（指の長さに対する割合）。**指がはみ出して見えたら上げる** | 0.34 |
| Toward Camera | 板をカメラのほうへ出す距離（m）。小さすぎると指に埋もれて見えなくなる | 0.35 |
| **Cell Pixels At 1080** | **モザイクのマス目の大きさ**（画面の高さ 1080 のときのピクセル数）。大きいほど粗い | 32 |
