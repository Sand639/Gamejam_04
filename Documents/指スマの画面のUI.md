## この機能は何か

企画のモックの見た目で、指スマの画面を作った（前の文字だけの仮の表示の代わり）。

| 場所 | 出るもの |
| --- | --- |
| 左上／右上 | プレイヤー名（1P は左上、2P は右上）。**番のプレイヤーは「▶ プレイヤー1 の番」** |
| 上の真ん中 | **取ったゲームの数を丸の画像で**（取ったら黒い丸） |
| 丸の下 | 番のプレイヤーの側だけ、操作の案内（「数字キー 0～4 で宣言 → スペース」） |
| 手の下 | **その手のキーの画像**（A・D・←・→）。スキルで固定されていれば「固定（下げたまま）」など |
| 下 | **「skill ＋ キーの画像」と、持っているスキルと短い説明**（例：「オッズ：奇数の宣言」）。無ければ「なし」 |
| 真ん中 | **吹き出し**。「いっせーの」、「指スマスタート！」、「1ゲーム目」、勝利など |
| 真ん中の下 | 結果（「1本！ プレイヤー1 当たり！」など） |
| 背景 | 1P は水色、2P はサーモン色（カメラの背景の色を変えている） |

### 吹き出しの出方

- **文字が変わるたびに、小さい状態からバンっと大きく出る**（少し行きすぎてから戻る）
- 「いっせーの」のあと数字が出る瞬間は、「いっせーの」を消し、**画面の真ん中に大きな吹き出しで「1！」だけ**を出す（スキルなら「サンダー！」など）

### スキルの短い説明（画面の下の欄）

| スキル | 表示 |
| --- | --- |
| サンダー | 宣言3で通れば勝ち |
| ピース | 宣言2で通れば勝ち |
| オッズ | 奇数の宣言 |
| イーブン | 偶数の宣言 |
| コンクリ | 下げた指が次の自分の手番まで固定 |
| セメント | 上げた指が次の自分の手番まで固定 |

結果のあとに真ん中へ出していたスキルの説明は、**出さなくした**（持っているスキルは下の欄に出ているため）。

### モックと違うところ

- **キーの画像は手の上ではなく、手の下に置いた。** 3D の手は中指を立てると画面の上の端近くまで伸びるので、上に置くと立てた指（とモザイク）に重なるため
- 手の後ろの白いカードは無い（3D の手なので）

## 付け方

**`Tools > Gamejam04 > 指スマの画面のUIを付ける`**

- **シーンを作り直さずに、今のシーンに付け足す**（`YubisumaUI` というオブジェクトが1つ増えるだけ。手の位置などの調整は消えない）
- すでに付いていれば、画像の割り当てだけやり直す
- UI の中身（文字・画像の配置）は、**再生を始めたときにコードで組み立てる**

## 設定できる値（`YubisumaUI` オブジェクト）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Key Sprites / Win Empty / Win Filled / Burst | 画像 | 上の表のもの |
| Font | 文字のフォント。空なら Unity の標準のフォント | 空 |
| **Panel Colors** | プレイヤーごとの背景の色 | 水色、サーモン色 |
| Frame Color / Text Color / Turn Color / Skill Box Color | 枠・文字・「の番」・スキルの欄の色 | ― |
| Key Icon Size / Win Mark Size | キーの画像・丸の大きさ（1920×1080 のとき） | 64 / 72 |
| Key Icon Below Hand | キーの画像を手の下にどれだけ離すか | 16 |
| **Pop Seconds** | 吹き出しが出てくるまでの時間（秒） | 0.25 |
| Pop Overshoot | 出てくるとき、どれだけ大きく行きすぎるか（0 なら行きすぎない） | 2.2 |
| **Reveal Scale** | 数字（スキル名）を出すときの吹き出しの大きさ（倍率） | 1.6 |
