## この機能は何か

指スマに**スキル**を足した。企画の「ギミック」の表の6つ。

| 名前 | 効果（企画の表のまま） | 実際の動き |
| --- | --- | --- |
| **コンクリ** | 下がっている相手の指を次の自分のターンまで上げられなくする | その番の「いっせーの ＜数字＞！」で**下がっていた相手の指**を固定。**使った人の次の番が終わるまで続く**（その番の判定にも効く） |
| **セメント** | 上がっている相手の指を次の自分のターンまで下げられなくする | 同じく、**上がっていた相手の指**を上げたまま固定 |
| **イーブン** | 手数が偶数なら得点 | その番は、**合計の本数が偶数なら当たり**（宣言した数字は関係なし） |
| **オッズ** | 手数が奇数なら得点 | その番は、**合計の本数が奇数なら当たり** |
| **ピース** | 2を宣言して的中した場合勝利する | **選ぶと宣言は自動で2になる**（数字キーは要らない）。**2本で当たったら、そのゲームに即勝ち**（手を1つ消すのではなく、ゲームを取る。**残っている手は全部いっしょに下へ流れて画面の外へ出る**） |
| **サンダー** | 3を宣言して的中した場合勝利する | **選ぶと宣言は自動で3になる**。**3本で当たったら、そのゲームに即勝ち**（ピースと同じく、残っている手は全部流れる） |

- ピース・サンダーは**スキル自体が「2／3を宣言する」**扱い。はずれたら**スキルは無くなるだけ**
- 数字で宣言するスキル（コンクリ・セメント）は、**先に数字キーを押してから**スキルを選ぶ（スキルを選んだあとに数字を押すと、スキルは取り消される）
- 固定された指は、キーを押しても離しても動かない。画面の左上に「固定：左 下げたまま」のように出る
- **固定された指は「いっせーの」の間も握りこぶしに戻らない。** セメントで上げたまま固定された指は、立ったまま見える

## 配る・使う・もらう

| いつ | どうなる |
| --- | --- |
| 試合の始め | 全員に**ランダムで1つ**配る |
| 自分の番（スペースを押す前） | スキルのキーで**選ぶ**（**画面には何も出ない**）。1回の番で選べるのは1つ。**選んだあとに数字キーが押されたら取り消し**（その番は数字で宣言する）。スキルのキーを押し直しても選んだまま |
| 「いっせーの」のあと | 「いっせーの ＜数字＞！」の**代わりに「いっせーの ＜スキル名＞！」**と出て、**そこで使われて無くなる** |
| 誰かが当てたとき | **当てていない側**がランダムで1つ**もらえる**。ただし**使わずに持っていたら、もらえない** |
| ゲーム（ラウンド）が変わるとき | 使わなかったスキルは**そのまま持ち越す**。固定は外れる |

- **相手の番では使えない**（押すと「スキルは自分の番でだけ使えます」と出る）
- 持っているスキルは、各プレイヤーの画面の左上に「スキル：コンクリ（W）」のように出る。**相手にも見える**
- **選んだことは相手にばれないようにしてある。** 左上の「スキル：」の表示も、画面下の「スキルは W」の案内も、選んでも変わらない（「いっせーの ＜スキル名＞！」で初めて分かる）
- スキル名が出ると数字が見えないので、結果に「宣言 2 → 2本！ 当たり！」と**宣言した数字も出す**（イーブン・オッズは数字を使わないので出さない）。あわせてスキルの効果の説明も出る
- **スキル名の声も鳴る**（`Assets/Audio/SE/コンクリート.wav` など）。「いっせーの ＜スキル名＞！」の瞬間に鳴る

## 操作

| プレイヤー | スキルを使うキー |
| --- | --- |
| プレイヤー1 | **W** |
| プレイヤー2 | **↑** |

### `Assets/Scripts/skills/Skills.cs` との関係

チームで作った `Skills.cs` は、**6つのスキルの名前と「使ったか」の記録**を持っている。
ただ、ターン・指・当たり判定とはつながっていなかったので、**`Skills.cs` には手を付けず**、
同じ6つのスキルを指スマの流れにつないだ `YubisumaSkill.cs` を別に作った。
（`Skills.cs` は日本語のコメントが Shift-JIS で保存されていて、UTF-8 で開くと文字化けする）

### シーンは作り直していない

指スマのシーン（`Yubisuma.unity`）は**メンバーが手の位置を調整済み**なので、作り直さずに動く作りにした。
スキルのキー（`Skill Keys`）は `YubisumaMatch` の新しい項目で、初期値（W ／ ↑）がそのまま入る。

## 設定できる値（`YubisumaMatch` オブジェクト）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| **Skill Keys** | スキルを使うキー。Players と同じ順 | W, ↑ |
| **Test Skill** | **テスト用。** None 以外にすると、**配るスキルももらうスキルも全部これになる**（ランダムにしない）。確かめたいスキルを選んで遊ぶ。**本番では None に戻すこと** | None |

## 決めたこと（企画の表に書かれていなかったところ）

AIが決めた。違っていたら直すこと。

- 「ラウンド」は BO3 の**1ゲーム**のこととした（使わなかったスキルはゲームをまたいで持ち越す）
- コンクリ／セメントは**使った番の「いっせーの ＜数字＞！」の瞬間**の相手の指を固定する。
  その番の判定には影響せず、**相手の次の番**と、**使った人の次の番（判定まで）**に効く。使った人の次の番が終わったら外れる
  （例：1Pが使う → 2Pの番 → 1Pの番の判定が終わるまで固定 → 外れる）。その番でまたコンクリ／セメントを使ったら、新しい固定に置き換える
- イーブン／オッズの「手数」は**上がっている指の合計**、「得点」は**当たり**（番のプレイヤーの手が1つ減る）とした
- ピース／サンダーの「勝利」は**そのゲームを取る**こと（試合全体の勝ちではない）とした

---

## できていないこと

- 使ったときの光などの演出は無い（文字とスキル名の声だけ）
- 選んだ本人にも「選んだ」と分かる表示が無い（相手にばれないようにするため）。押し間違えたかどうかは、いっせーのまで分からない
- 相手のスキルを隠す仕組みは無い（画面を分けて見ているが、1台の画面なので見える）
