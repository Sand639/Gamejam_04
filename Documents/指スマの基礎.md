## この機能は何か

**指スマのローカル対戦の土台。** 1台のPC・1つのキーボードで2人が遊ぶ前提。

- 画面を左右に2分割する。**左がプレイヤー1、右がプレイヤー2**
- 各プレイヤーは両手の親指を持つ。**キーを押している間、親指が上がる**
- 画面に、それぞれ上げている本数と、**全員の合計**が出る

### 試合の流れ（`YubisumaMatch`）

1. タイトルから切り替わると、**「指スマスタート！」** が出る
2. 番のプレイヤーが**数字キー（0〜4）**で本数を指定する
   - **画面には出さない。** 最後に押した数字を覚えておく（押さなければ 0）
   - **5〜9 を押すと 0 になる**。テンキーも使える
   - 指定した数字は、いっせーのが終わっても**そのまま残る**
3. **スペース**で「いっせーの」→ 1.5秒遅れて、**指定していた数字を「いっせーの 2！」のように出す**
4. **数字を出した瞬間**に上がっている親指の合計（2人分）が、指定した数と同じなら**当たり**
   - 番のプレイヤーの手を**1つ**（右手から先に）下へ流して画面の外へ出し、**消す**
   - 消えた手は、キーを押しても動かず、本数にも数えない
5. 当たってもはずれても、**いっせーのごとに番を交代**する
6. 両手とも消えたプレイヤーの**勝ち**（「○○ の勝ち！」と出て止まる）

画面の下に、いまの番と合計の本数が出る。

## 操作

| プレイヤー | 左手 | 右手 |
| --- | --- | --- |
| プレイヤー1（左の画面） | **A** | **D** |
| プレイヤー2（右の画面） | **←** | **→** |

| キー | 役割 |
| --- | --- |
| **0〜4** | 番のプレイヤーが本数を指定する（5〜9 は 0 になる） |
| **スペース** | いっせーの |

### 手の動かし方

- 手のプレハブの Animator には、元の `HandController` ではなく **`YubisumaHand.controller`** を入れてある。
  元のほうは Idle から中指を立てるポーズ（Hand_Fuck）へ自動で移るため、指スマでは使わない。**元のコントローラーは変えていない**
- 用意されたアニメーションには**親指を上げるポーズが無い**。
  そのため、キーを押している間だけ、**スクリプトで親指の骨（Thumb・Thumb2）を上へ向けて上書き**している
  （アニメーションのあと＝LateUpdate で回すので、元のポーズは崩れない）
- 下げているときは、握りこぶしのアニメーションのまま（親指は横に寝ている）

### シーンの中身

```
Yubisuma
├── Directional Light
├── Player1               ← YubisumaPlayer（x = -20 に置いてある）
│   ├── Camera            ← 画面の左半分（Viewport Rect: X 0 / W 0.5）。手の後ろから映す
│   ├── LeftHand  … 手のプレハブ ＋ YubisumaThumb（A）   ← x = +0.5（後ろから見て左）
│   └── RightHand … 手のプレハブ ＋ YubisumaThumb（D）   ← x = -0.5（後ろから見て右）
├── Player2               ← x = +20。カメラは画面の右半分
│   ├── LeftHand  … ←
│   └── RightHand … →
├── YubisumaHud           ← 名前・キー・本数・合計・仕切り線
└── YubisumaMatch         ← 試合の流れと、真ん中の大きな文字
```

**2人の手は離れた場所に置き、それぞれ専用のカメラで映している。**
画面分割は、カメラの **Viewport Rect** で左右に割り当てているだけ。
**カメラは手の後ろ（+Z 側）から映す**（自分の手を見ている向き。左に左手、右に右手が出る。`BothHands` の並べ方と同じ）。

## 設定できる値

### Yubisuma Thumb（各手の一番上 `LeftHand` ／ `RightHand`）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| **Key** | この親指を上げるキー | A／D／←／→ |
| **Mode** | **Hold**：押している間だけ上がる ／ **Toggle**：押すたびに切り替わる | Hold |
| Thumb Root / Thumb Middle / Thumb Tip | 親指の骨（付け根 Thumb ／ 真ん中 Thumb2 ／ 先の _end）。シーンを作るときに自動で入る | ― |
| Raised Direction | 上げたときに親指を向ける方向（手を基準）。**斜めにしたいときはここを変える** | (0, 1, 0)＝真上 |
| Turn Speed | 上げ下げの速さ | 25 |

### Yubisuma Player

| 項目名 | 意味 |
| --- | --- |
| Display Name | 画面に出す名前 |
| Thumbs | このプレイヤーの親指（左手・右手） |
| Player Camera | このプレイヤーを映すカメラ |

### Yubisuma Match（`YubisumaMatch` オブジェクト）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Players | 参加するプレイヤー。この順に番が回る | Player1, Player2 |
| Intro Seconds | 「指スマスタート！」を出しておく時間（秒） | 1.5 |
| **Call Delay Seconds** | **「いっせーの」から「いっせーの ＜数字＞！」までの遅れ（秒）** | 1.5 |
| Result Seconds | 「いっせーの ＜数字＞！」と結果を出しておく時間（秒）。この間はスペースを受け付けない | 1.5 |
| Scroll Distance | 当てた手を下へ流す距離（m） | 8 |
| Scroll Seconds | 当てた手を下へ流す時間（秒） | 1.0 |

## できていないこと（次にやること）

- 指定した数字が画面に出ないので、押し間違えても分からない（いっせーのの最後に初めて出る）
- 勝負がついたあと、もう一度遊ぶ／タイトルへ戻る方法が無い
- 親指は骨を回して上げているだけ。本格的な「親指を上げるアニメーション」ができたら差し替える
- 画面の表示（文字・仕切り線）は仮のもの
- 数字キーは誰でも押せる（番のプレイヤーだけに限っていない）
