## この機能は何か

**指スマのローカル対戦の土台。** 1台のPC・1つのキーボードで2人が遊ぶ前提。

- 画面を左右に2分割する。**左がプレイヤー1、右がプレイヤー2**
- 各プレイヤーは両手を持つ。**キーを押している間、その手の中指が立つ**
- 画面に、それぞれ上げている本数と、**全員の合計**が出る

### 試合の流れ（`YubisumaMatch`）

1. タイトルから切り替わると、**「指スマスタート！」** が出る
2. 番のプレイヤーが**数字キー（0〜4）**で本数を指定する
   - **画面には出さない。** 最後に押した数字を覚えておく（押さなければ 0）
   - **5〜9 を押すと 0 になる**。テンキーも使える
   - 指定した数字は、いっせーのが終わっても**そのまま残る**
3. **スペース**で「いっせーの」→ 1.5秒遅れて、**指定していた数字を「いっせーの 2！」のように出す**
   - **「いっせーの」が始まると、全員の手を握りこぶしに戻す。** キーを押していても指は立たない
   - キーを**押し続けていれば**、「いっせーの ＜数字＞！」の瞬間に**一斉に指が立つ**
   - 結果を出している間は、その瞬間の形のまま止めておく（見えている本数と判定を合わせるため）
   - **声も鳴る。** スペースを押すと「いっせーの」、数字を出す瞬間にその数字（0〜4）の声
4. **数字を出した瞬間**にキーを押している手の合計（2人分）が、指定した数と同じなら**当たり**
   - 番のプレイヤーの手を**1つ**（画面の右側の手から先に）、**指を立てた形のまま**下へ流して画面の外へ出し、**消す**
   - 消えた手は、キーを押しても動かず、本数にも数えない
5. 当たってもはずれても、**いっせーのごとに番を交代**する。交代したら、手はふだんの動き（キーを押すとすぐ立つ）に戻る
6. 両手とも消えたプレイヤーが**そのゲームを取る**
7. **先に2ゲーム取ったプレイヤーの勝ち（BO3）**。「○○ の勝ち！ 2 - 1」と出て止まる
   - まだ決まらなければ「○○ が 1ゲーム目を取った！」と出し、**全員の手を両手とも元に戻して**次のゲームへ
   - 次のゲームは**取られた側（負けた側）の番から**始まる
   - 当たった手は壊さず、画面の外に流して**非表示**にしておき、次のゲームで元の位置に戻す

画面の下に、ゲームのスコア（「プレイヤー1  1 - 0  プレイヤー2」）、いまの番、合計の本数が出る。
**本数は「見えている指」の数**なので、「いっせーの」の間は 0 本になる（本数がばれないように）。

### 手の動かし方

- **上げている＝中指を立てる（Hand_Fuck）**、**下げている＝握りこぶし（Hand_Idle）**
- 手のプレハブの Animator には、元の `HandController` ではなく **`YubisumaHand.controller`** を入れてある。
  元のほうは**キーに関係なく** Idle から中指へ移ってしまうため、指スマでは使わない。**元のコントローラーは変えていない**
- `YubisumaHand.controller` は Bool パラメーター **`Raised`** で切り替わる（ON で中指、OFF で握りこぶし。待たずに 0.08秒で移る）
- ポーズを変えたいときは、`YubisumaHand.controller` の2つの状態に入っているアニメーションを差し替えればよい

### シーンの中身

```
Yubisuma
├── Directional Light
├── Player1               ← YubisumaPlayer（x = -20 に置いてある）
│   ├── Camera            ← 画面の左半分（Viewport Rect: X 0 / W 0.5）。手の後ろから映す
│   ├── RightHand … 右手のプレハブ ＋ YubisumaThumb（A）   ← x = +0.5（画面の左）
│   └── LeftHand  … 左手のプレハブ ＋ YubisumaThumb（D）   ← x = -0.5（画面の右）
├── Player2               ← x = +20。カメラは画面の右半分
│   ├── RightHand … ←（画面の左）
│   └── LeftHand  … →（画面の右）
├── YubisumaHud           ← 名前・キー・本数・合計・仕切り線
└── YubisumaMatch         ← 試合の流れと、真ん中の大きな文字
```

**2人の手は離れた場所に置き、それぞれ専用のカメラで映している。**
画面分割は、カメラの **Viewport Rect** で左右に割り当てているだけ。
**カメラは手の後ろ（+Z 側）から映す。** 手は**左右を入れ替えて**置いてあり、**画面の左に右手、右に左手**が出る（親指が外側を向く）。
**キーは画面の並びに合わせてある**（画面の左の手が A／←、右の手が D／→）。手のモデルの左右とは逆なので注意。画面の案内も「左 A ／ 右 D」と画面の位置で出す。

## 設定できる値

### Yubisuma Thumb（各手の一番上 `LeftHand` ／ `RightHand`）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| **Key** | この手の指を立てるキー | A／D／←／→ |
| **Mode** | **Hold**：押している間だけ上がる ／ **Toggle**：押すたびに切り替わる | Hold |
| Animator | 手の Animator。シーンを作るときに自動で入る | ― |
| Raised Parameter | 切り替えに使う Animator の Bool パラメーター | Raised |

### Yubisuma Player

| 項目名 | 意味 |
| --- | --- |
| Display Name | 画面に出す名前 |
| Thumbs | このプレイヤーの手（左手・右手） |
| Player Camera | このプレイヤーを映すカメラ |

### Yubisuma Match（`YubisumaMatch` オブジェクト）
| **Wins To Win Match** | 何ゲーム先に取ったら勝ちか。2＝BO3、3＝BO5 | 2 |
| Game Result Seconds | ゲームを取ったあと、次のゲームを始めるまでの時間（秒） | 2.5 |

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Players | 参加するプレイヤー。この順に番が回る | Player1, Player2 |
| Intro Seconds | 「指スマスタート！」や「○ゲーム目」を出しておく時間（秒） | 1.5 |
| **Call Delay Seconds** | **「いっせーの」から「いっせーの ＜数字＞！」までの遅れ（秒）** | 1.5 |
| Result Seconds | 「いっせーの ＜数字＞！」と結果を出しておく時間（秒）。この間はスペースを受け付けない | 1.5 |
| Scroll Distance | 当てた手を下へ流す距離（m） | 8 |
| Scroll Seconds | 当てた手を下へ流す時間（秒） | 1.0 |
| Voice Source | 声を鳴らす AudioSource（2D の音） | YubisumaMatch に付いているもの |
| **Isseeno Voice** | 「いっせーの」の声 | `Assets/Audio/いっせーの.wav` |
| **Number Voices** | 数字の声。0〜4 の順 | `Assets/Audio/0.wav`〜`4.wav` |

## できていないこと（次にやること）

- 指定した数字が画面に出ないので、押し間違えても分からない（いっせーのの最後に初めて出る）
- 試合（BO3）が決まったあと、もう一度遊ぶ／タイトルへ戻る方法が無い
- 指スマ本来の「親指」ではなく、いまは中指のアニメーションで上げ下げしている
- 画面の表示（文字・仕切り線）は仮のもの
- 数字キーは誰でも押せる（番のプレイヤーだけに限っていない）
